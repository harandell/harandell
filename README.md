- **[Data Review Agent](https://github.com/harandell/harandell-portfolio/tree/main/data-review-agent)** — an LLM agent that finds gaps in customers' data, asks them the right

- **[Unstructured Data Pipeline](https://github.com/harandell/harandell-portfolio/tree/main/unstructured-data-pipeline)** — turns messy farm documents (PDFs, scans, handwriting) into

And on the personal side, [an LLM agent](https://github.com/harandell/harandell-portfolio/tree/main/strava-logging-agent) that keeps a six-year Strava journal in order.
